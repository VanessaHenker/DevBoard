# 🚀 DevBoard

Aplicação full-stack desenvolvida para gerenciamento de tarefas, organização de projetos e estudos de arquitetura moderna com integração entre front-end e banco de dados.

---

## ✨ Sobre o projeto

O DevBoard foi criado como parte da minha jornada de aprendizado em desenvolvimento full-stack, com foco na construção de aplicações modernas, componentização, autenticação de usuários e persistência de dados.

O projeto tem como objetivo aprofundar conhecimentos em organização de aplicações, integração com APIs e boas práticas de desenvolvimento.

---
