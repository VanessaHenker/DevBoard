# ✨ Sobre o Projeto

O **DevBoard** é uma aplicação full-stack desenvolvida com foco em evolução técnica, arquitetura moderna e construção de interfaces escaláveis.

O projeto simula um ambiente de gerenciamento de tarefas e projetos, explorando conceitos utilizados em aplicações reais do mercado.

<div align="center">

💡 *Mais do que um CRUD, o DevBoard representa minha evolução como desenvolvedora.*
