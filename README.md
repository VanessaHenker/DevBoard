# 🚀 DevBoard

Sistema full-stack de gerenciamento de tarefas e projetos, desenvolvido com foco em arquitetura moderna, boas práticas de desenvolvimento e evolução técnica.

---

## 📌 Sobre o projeto

O **DevBoard** é uma aplicação web que simula um sistema real de produtividade, permitindo que usuários criem, organizem e gerenciem tarefas dentro de projetos.

A proposta do projeto é ir além de um simples CRUD, explorando:

- Estrutura de aplicações escaláveis
- Separação de responsabilidades (frontend/backend)
- Integração com banco de dados
- Autenticação de usuários
- Organização por módulos

---

## 🎯 Objetivos do projeto

Este projeto foi criado com o objetivo de:

- Praticar desenvolvimento full-stack na prática
- Entender arquitetura de aplicações reais
- Evoluir habilidades com React + TypeScript
- Trabalhar integração com backend e banco de dados
- Simular um produto funcional de mercado

---

## ⚙️ Tecnologias utilizadas

### Frontend
- React
- TypeScript
- Vite
- CSS moderno

### Backend
- Node.js
- Express (ou Supabase)
- PostgreSQL

### Banco de dados
- PostgreSQL / Supabase
