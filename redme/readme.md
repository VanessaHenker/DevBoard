# DevBoard

Projeto de estudos full-stack desenvolvido para praticar gerenciamento de tarefas, organização de projetos e integração entre front-end e banco de dados.

## Tecnologias
- React
- TypeScript
- Supabase
- PostgreSQL
- CSS

## Funcionalidades
- Criação de tarefas
- Edição de tarefas
- Exclusão de tarefas
- Organização de projetos
- Persistência de dados
- Autenticação de usuários

## Estrutura do Projeto

```bash
frontend/
backend/
sql/
```

## Conceitos estudados
- CRUD completo
- Integração React + Supabase
- Estruturação de banco de dados
- Queries SQL
- Autenticação
- Organização de componentes
- Gerenciamento de estado

## Sobre o projeto
Este projeto faz parte da minha jornada de aprendizado em desenvolvimento full-stack, com foco em arquitetura, organização de aplicações e integração com banco de dados.
